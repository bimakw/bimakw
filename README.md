### About

Senior Cloud Infrastructure Engineer at PT. Indomarco Prismatama (Indomaret Group) — 6+ years operating production cloud platforms across GCP, Kubernetes, Terraform, and HashiCorp Vault.

I run **cost-aware infrastructure**: Committed Use Discounts (CUD) for steady-state workloads, Spot/Preemptible GCE for fault-tolerant jobs, and self-hosted observability stacks to avoid Cloud Logging ingestion charges. Sustained zero board-level cost complaints over 2 years while infrastructure kept expanding.

Currently focused on Kubernetes platform engineering (K3s/GKE), ArgoCD GitOps, Vault dynamic secrets, IAP-secured workloads, and Terraform-driven provisioning across hybrid cloud/on-premise environments. Former Technical Lead (2021–2026) across four engineering squads — that role closed July 2026 to focus full-time on cloud.
